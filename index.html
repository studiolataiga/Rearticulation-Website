Built around how you already work in REAPER

Banks are plain JSON files

One file per bank. Open it in any text editor, keep it in version control, or send it to a collaborator. Nothing is locked inside a project.

One plugin per track

A JSFX MIDI plugin on each track holds its bank assignment. Copy and paste the plugin between tracks and the assignment comes with it.

An editor inside REAPER

Open the editor from the plugin to create banks and edit articulations without leaving your project. It is built with ReaImGui, so there is no separate app to launch.

Notes land where you played them

Some instruments respond later to some articulations. Rearticulation holds MIDI events back and re-emits them at a shifted time, so the sound arrives where you played it.

It works on MIDI events only. Your audio is never touched.

From bank to track in three steps

  1. Create or pick a bank

    Describe an instrument’s articulations in a JSON file, or open the editor and build the bank there.

  2. Add the plugin to a track

    Insert the JSFX on a track and assign the bank. Copy the plugin to other tracks that use the same instrument.

  3. Edit whenever you need to

    Launch the editor from the plugin, change an articulation, and keep working in the same project.

The editor

Every articulation in a bank, with its own latency, velocity range, exclusion group, note length and the MIDI messages it sends.

Questions

What do I need to run it?

REAPER and the ReaImGui extension, which is free and installs through ReaPack. The track plugin is a JSFX, which REAPER runs natively.

Can I import my .reabank files?

No. Rearticulation uses its own JSON format and does not read .reabank files.

Does it change my audio?

No. Delay compensation shifts MIDI events only. Audio streams are never touched.

Is it a fork of Reaticulate?

No. Rearticulation is a ground-up rewrite, inspired by the open-source Reaticulate. Anything borrowed is credited under Reaticulate’s Apache 2.0 license.
